# Small War 地图路径处理规范

> 基于 Assembly-CSharp.dll 反编译分析

## 一、文件系统路径体系

### 1.1 路径计算方法（SaveManager 静态方法）

| 方法                            | 返回类型 | 用途             | 说明                  |
|---------------------------------|----------|------------------|-----------------------|
| `SaveManager.DataPath()`        | `string` | 基础数据根目录   | 游戏存档/配置的根路径 |
| `SaveManager.GeneralMapPath()`  | `string` | 通用地图目录     | 标准对战地图存放位置  |
| `SaveManager.CampaignMapPath()` | `string` | 战役地图目录     | 单人战役关卡地图      |
| `SaveManager.SettingPath()`     | `string` | 设置文件路径     | 游戏配置存档          |
| `SaveManager.DeckPath()`        | `string` | 卡组目录         | 玩家自定义卡组        |
| `SaveManager.GamePath()`        | `string` | 全局游戏数据路径 | `GameData` 存档位置   |
| `SaveManager.WorksPath()`       | `string` | 本地工作区目录   | 地图编辑器工作区      |

> **重要**: 所有路径必须通过 `SaveManager` 静态方法获取， **禁止硬编码**。不同平台（Windows/Mac/Linux）路径格式不同，硬编码会导致跨平台失败。

## 二、地图文件扫描路径

### 2.1 官方地图扫描

```csharp
// 按地图类型筛选官方地图
List<string> officialMaps = SaveManager.FindAllOfficialMap(int mapType);
```

**扫描路径**: 游戏安装目录下的官方地图文件夹 **返回**: 地图文件名列表（不含路径和扩展名）

### 2.2 玩家地图扫描

```csharp
// 按地图类型筛选玩家自定义地图
List<string> playerMaps = SaveManager.FindAllPlayerMap(int mapType);
```

**扫描路径**: `SaveManager.GeneralMapPath()` 或 `SaveManager.CampaignMapPath()`
**返回**: 地图文件名列表

### 2.3 自定义目录扫描

```csharp
// 扫描任意目录下的地图
List<string> maps = SaveManager.FindAllMapFromFolder(string folderPath, int mapType);
```

**参数**:

- `folderPath`: 目标目录绝对路径
- `mapType`: 地图类型过滤（-1 表示全部）

## 三、地图加载路径

### 3.1 通用路径加载

```csharp
// 从任意路径加载地图
MapData mapData = SaveManager.LoadMap(string path);
```

**适用场景**: 编辑器打开外部地图、Mod 加载自定义目录地图 **路径格式**: 完整绝对路径，包含文件名和扩展名

### 3.2 玩家地图加载

```csharp
// 从玩家地图目录加载
MapData mapData = SaveManager.LoadPlayerMap(string mapName, int type);
```

**路径解析**:

1. 拼接 `SaveManager.GeneralMapPath()` + `mapName` + 扩展名
2. 根据 `type` 选择子目录（如有分类）

### 3.3 官方地图加载

```csharp
// 从官方地图目录加载
MapData mapData = SaveManager.LoadOfficialMap(string mapName, int type);
```

**路径解析**:

1. 拼接游戏安装目录 + 官方地图子目录 + `mapName` + 扩展名
2. 通常只读，Mod 不应尝试写入

### 3.4 完整战局加载（含地图）

```csharp
// 加载存档（包含地图 + 单位状态）
SaveData saveData = SaveManager.Load(string saveName);
// 或
MapCreater.Instance.Load(saveData);
```

**加载流程**:

```
SaveManager.Load(saveName)
  -> 反序列化 SaveData
  -> SaveData 内含 MapData 和 UnitSaveData[]
  -> MapCreater.Load(saveData)
       -> 调用 LoadMap(mapData) 重建地形
       -> 调用 CreateUnit(UnitSaveData) 恢复单位状态
```

## 四、地图保存路径

### 4.1 玩家地图保存

```csharp
// 保存到玩家地图目录
SaveManager.SavaPlayerMap(MapData data, string mapName, int type);
```

**注意**: 方法名 `Sava` 为程序集原始拼写，非 `Save`。

**保存路径**:

```
{SaveManager.GeneralMapPath()}/{type}/{mapName}.json
```

### 4.2 完整战局保存

```csharp
// 保存完整游戏存档
SaveManager.Sava(SaveData data, string saveName);
```

**保存内容**: 包含当前地图状态、所有单位运行时状态、玩家数据等

### 4.3 工作区操作

```csharp
// 创建工作区
SaveManager.CreateWorkFolder(string workName);

// 复制地图到工作区
SaveManager.CopyMapToWork(string mapName, int type, string workName);

// 删除工作区
SaveManager.DeleteWork(string workName);

// 删除工作区中的地图
SaveManager.DeleteMapFromWork(string workName, string mapName, int type);
```

**工作区路径**:

```
{SaveManager.WorksPath()}/{workName}/
```

## 五、运行时地图加载路径

### 5.1 从 MapData 创建战局

```text
MapCreater.Init()
  -> MapCreater.LoadMap(mapData)
       -> 写入尺寸、类型、tileDataList、playerDatas
       -> CreateMap()
            -> Rule.Instance.GetPrefab()      [获取地形预制体]
            -> DeleteMap()                     [清理旧地图实例]
            -> foreach TileData in tileDataList:
                  CreateTile(type, position, rotation)
                  -> 设置 NewHexagon.tileData
                  -> Rule.GetCellData(type)    [查询地形规则]
            -> 创建 CellGrid 和地图附属对象（迷雾、边界等）
       -> CreatePlayer(mapData)
            -> 根据 EasyPlayerData 构造 PlayerData
            -> 实例化 NewHumanPlayer / NewAiPlayer
            -> 设置 PlayerNumber、team、money、camp、科技和锁定项
            -> MyPlayer.Init()
       -> foreach EasyUnitData in unitData:
             CreateUnit(easyUnitData, playerNumber)
               -> CreateUnit(simpleName, position, player)
                   -> 分配 GameManager.MaxUnitIndex
                   -> Rule.InitUnit(newUnit, id, playerData)
                   -> 设置 sourcePlayerNumber / TAG / Command
                   -> NewUnit.Initialize()
```

### 5.2 随机地图创建路径

```text
MapCreater.CreateRandomWar()
  -> RandomMapCreater / BaseMapStrategy 子类
  -> 生成随机 tile / hill / tree / money / city / fog 列表
  -> 构造 MapData（内存中，不保存到文件）
  -> CreateMap()              [复用相同的地形实例化逻辑]
  -> CreatePlayer(...)        [创建玩家]
  -> 创建基础单位和玩家起始单位
  -> CellGrid 开始回合
```

### 5.3 地图编辑器加载路径

```text
MapMaker.LoadMap(mapData)
  -> 装载地图到编辑器场景
  -> 生成可编辑的 CellEditor / UnitEditor 对象
  -> 支持画笔、单位放置、玩家修改、镜像等操作
  -> MapMaker.GetMapData() 可序列化回 MapData
```

## 六、联机地图同步路径

### 6.1 设计原则

**地图数据本身不走网络同步**。联机时各客户端独立加载相同的 `MapData`，通过操作指令同步保持一致。

### 6.2 联机启动流程

```text
主机
  -> 选择/生成 MapData
  -> 发送地图名称/种子给客户端（或通过 Steam Workshop 共享）
  -> 客户端独立加载相同 MapData

所有客户端
  -> MapCreater.LoadMap(mapData)  [各自执行相同的加载流程]
  -> 生成一致的初始状态
  -> NetPlayer 连接建立
  -> 游戏开始，后续通过 Cmd/Rpc 同步操作
```

### 6.3 网络坐标约束

| 层级       | 坐标类型                | 说明                              |
|------------|-------------------------|-----------------------------------|
| 网络传输   | `Vector2` 偏移坐标      | 所有 `Cmd*` / `Rpc*` 使用偏移坐标 |
| 客户端解析 | 偏移坐标 → Cell/NewUnit | 根据坐标查找本地对象              |
| 实例化     | `Vector3` 世界坐标      | 仅 `MapCreater` 内部使用          |

> **警告**: 单位销毁、地图变更或坐标重复时，不能仅依赖旧的 `Vector2` 定位。联机模式下 **严禁动态修改地图地形**，否则坐标映射将失效。

## 七、坐标转换路径

### 7.1 偏移坐标 → 世界坐标

```csharp
// MapCreater 提供的转换方法
Vector3 worldPos = MapCreater.Instance.OffsetCoordToPosition(Vector3 offsetCoord);
```

**使用场景**:

- `MapCreater.CreateTile()` 内部转换
- 网络坐标接收后的对象查找
- 存档坐标恢复

### 7.2 世界坐标 → 偏移坐标

游戏内未提供显式的逆向转换方法，通常通过 `CellGrid` 或 `NewHexagon` 的反向查找实现：

```csharp
// 通过 Cell 对象获取偏移坐标
Vector2 offset = cell.OffsetCoord;  // NewHexagon 属性
```

## 八、路径使用规范

### 8.1 Do（推荐）

```csharp
// 使用 SaveManager 方法获取路径
string mapPath = SaveManager.GeneralMapPath();
string savePath = SaveManager.DataPath();

// 使用 SaveManager 方法加载/保存
MapData map = SaveManager.LoadPlayerMap("MyMap", 1);
SaveManager.SavaPlayerMap(map, "MyMap", 1);
```

### 8.2 Don't（禁止）

```csharp
// 硬编码路径（跨平台会失败）
string badPath = "C:\Users\Name\AppData\SmallWar\maps";

// 假设路径结构
string badPath2 = Application.dataPath + "/save/maps";

// 直接操作文件而不通过 SaveManager
File.WriteAllText("some/path/map.json", json);
```

## 九、Mod 路径操作示例

### 9.1 读取自定义地图目录

```csharp
// 加载 Mod 自带的地图
string modMapFolder = Path.Combine(ModManager.ModPath, "Maps");
List<string> modMaps = SaveManager.FindAllMapFromFolder(modMapFolder, -1);

foreach (string mapName in modMaps)
{
    string fullPath = Path.Combine(modMapFolder, mapName + ".json");
    MapData mapData = SaveManager.LoadMap(fullPath);
    // 注册到游戏...
}
```

### 9.2 动态注入地图到玩家目录

```csharp
// 将 Mod 地图复制到玩家地图目录，使其出现在游戏 UI 中
string modMapPath = Path.Combine(ModManager.ModPath, "Maps/MyModMap.json");
MapData mapData = SaveManager.LoadMap(modMapPath);
SaveManager.SavaPlayerMap(mapData, "MyModMap", mapData.type);
```

### 9.3 备份与恢复

```csharp
// 备份当前地图到工作区
SaveManager.CreateWorkFolder("Backup_" + DateTime.Now.ToString("yyyyMMdd"));
SaveManager.CopyMapToWork("CurrentMap", 1, "Backup_20260814");

// 从工作区恢复
string workMapPath = Path.Combine(SaveManager.WorksPath(), "Backup_20260814/CurrentMap.json");
MapData backup = SaveManager.LoadMap(workMapPath);
```
