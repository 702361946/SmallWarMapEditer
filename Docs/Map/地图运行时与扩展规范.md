## 二、地形规则系统（CellData）

### 2.1 地形规则查询

```csharp
// 运行时查询地形规则
CellData cellData = Rule.Instance.GetCellData(int id);
```

### 2.2 CellData 结构

| 字段            | 类型           | 说明       |
|---------------|--------------|----------|
| `id` / `name` | `int`        | 地形类型ID   |
| `groundType`  | `GroundType` | 地面类型     |
| `moveCost`    | `float`      | 单位移动消耗   |
| `money`       | `bool`       | 是否产生金钱收入 |
| `notBuilding` | `bool`       | 是否禁止建造   |
| `sprite`      | `Sprite`     | 地形显示图片   |
| `miniSprite`  | `Sprite`     | 小地图显示图片  |

### 2.3 GroundType 枚举

| 值   | 名称      | 说明             |
|-----|---------|----------------|
| `0` | `Land`  | 陆地，所有地面单位可通行   |
| `1` | `Water` | 水域，仅海军/两栖单位可通行 |
| `2` | `Wall`  | 障碍，不可通行/不可建造   |

### 2.4 地形表来源

地形规则存储在 `CellTable`（`UnityEngine.ScriptableObject`）中：

```
Rule.Awake()
  -> InitCellData()
       -> 从 CellTable 加载所有 CellData
       -> 存入 Rule.cellDataDic（按 id 索引）
```

## 七、联机地图约束

### 7.1 禁止操作

联机模式下**严禁**以下操作：

| 操作                   | 风险                    |
|----------------------|-----------------------|
| 动态修改 `tileDataList`  | 客户端地形不一致，坐标映射失效       |
| 运行时增删格子              | `CellGrid` 状态不同步，寻路崩溃 |
| 修改 `bothPlace`       | 出生点不一致，玩家加载到错误位置      |
| 直接操作 `NewHexagon` 属性 | 绕过网络同步，状态分叉           |

### 7.2 允许操作

以下操作在联机模式下安全：

| 操作     | 前提                 |
|--------|--------------------|
| 读取地形信息 | 仅本地查询，不修改          |
| 计算路径   | 使用本地 `CellGrid` 数据 |
| 显示范围指示 | 纯 UI 层，不影响逻辑       |

### 7.3 地图同步替代方案

若需联机使用自定义地图：

1. **预共享**：通过 Steam Workshop 或文件传输，确保所有客户端拥有相同地图文件
2. **种子同步**：主机发送随机种子，客户端使用相同种子生成一致地图
3. **哈希校验**：加载前比对地图文件哈希值，不一致则拒绝加入

## 十、调试与故障排查

### 10.1 地图加载失败排查

```text
1. 检查 Rule.Instance 是否为 null
   -> 确保在 Rule.Awake() 后操作

2. 检查 tileDataList.Count == width * height
   -> 不匹配会导致 CreateMap() 越界或缺格

3. 检查所有 tileData.type 在 Rule.cellDataDic 中存在
   -> 缺失会导致 GetCellData() 返回 null，InitCell() 崩溃

4. 检查 bothPlace.Length == playerDatas.Length
   -> 不匹配会导致出生点索引越界

5. 检查 unitData[].PlayerNumber 在 [1, playerDatas.Length-1]
   -> 为 0 会导致单位归属异常
   -> 越界会导致玩家数据索引越界

6. 检查 unitData[].pos 在地图边界内
   -> 越界会导致单位放置到无效格子
```

### 10.2 常见错误

| 现象          | 原因                                | 解决                       |
|-------------|-----------------------------------|--------------------------|
| 地图加载后黑屏/无地形 | `tileDataList` 为空或数量不匹配           | 检查 `width × height`      |
| 单位不显示       | `PlayerNumber = 0` 或越界            | 改为有效玩家编号                 |
| 出生点错误       | `bothPlace` 与 `playerDatas` 长度不一致 | 统一为 9 位，无效位填 `(255,255)` |
| 联机不同步       | 客户端地图文件不一致                        | 确保使用相同地图数据               |
| 编辑器保存后加载异常  | `MapMaker.GetMapData()` 遗漏字段      | 检查所有必填字段                 |
